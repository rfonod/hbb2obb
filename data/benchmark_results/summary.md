## Per-run detail

Each `<run>/` folder holds `run_config.yaml` (the resolved settings and the host it ran on),
`results.yaml` (every grid point), `summary.txt` (the same, human readable) and
`plot.png` (average IoU against scale factor, coloured by image size).

The time column is one pass over the image set with the models already loaded. Checkpoint
loading is timed separately, as `model_load_seconds` in each `results.yaml`.
